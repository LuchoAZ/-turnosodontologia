# Backend — Gestión Odontológica PyME

FastAPI (Python 3.12) service scaffold generated by change `c-01-foundation-setup`.

- Install: `uv sync` (dev tools — ruff/mypy/pytest — come from the default `dev` dependency group)
- Run API: `uvicorn app.main:app --reload`
- Lint / types: `uv run ruff check .` · `uv run mypy app`
- Tests: `uv run pytest`
